# Michelle Nhengu — Administrative Portfolio Website

A responsive, static portfolio website for an entry-level Junior Data Entry and Office Operations Assistant application.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive styling
- `script.js` — fictional sample supplier records, summary cards and mobile navigation

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the page remains readable if they are unavailable.

## Before publishing
Replace:
- `[YOUR EMAIL]` / `YOUR.EMAIL@example.com` with your real professional email.
- Any placeholder phone number if you decide to add one.
- Confirm the LinkedIn URL is correct.

The sample supplier data, tasks, meeting information and email are fictional portfolio demonstrations. Do not describe them as paid client work or actual employer records.

## Publish
You can deploy this static site using GitHub Pages, Netlify or Render Static Sites. Upload the contents of this folder (not the ZIP itself) to the chosen static hosting service.
